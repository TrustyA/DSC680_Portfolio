Childcare Affordability Analysis
Overview

This project explores childcare affordability across the United States using data analysis and visualization techniques. The analysis examines how childcare costs vary by location and how those costs compare to household income levels.

Objective

The objective of this project was to identify trends in childcare affordability and highlight regions where childcare expenses place a significant financial burden on families.

Data

The project utilized publicly available childcare cost and demographic data containing information on childcare expenses, income levels, and geographic location.

Tools & Technologies

Methodology

The data was cleaned and prepared for analysis by handling missing values and standardizing relevant fields. Exploratory data analysis was performed to identify patterns and relationships between childcare costs and income levels. Visualizations were created to communicate findings effectively.

Results

The analysis showed significant regional differences in childcare affordability. In many areas, childcare costs represented a substantial percentage of household income, highlighting affordability challenges faced by working families.
