Video Game Install Size vs Ratings and Reviews
Overview

This project explores whether larger video game install sizes correlate with higher review scores, user ratings, or overall game quality.

Objective

The objective was to examine the relationship between storage requirements and consumer reception using data-driven analysis.

Data

Video game metadata including install size, review scores, ratings, and other game characteristics.

Tools & Technologies
Python
Pandas
NumPy
Matplotlib
Seaborn
Methodology

Exploratory data analysis and visualization techniques were used to identify trends and relationships between install size and review metrics.

Results

The analysis found that larger install sizes do not necessarily correspond to higher ratings or improved player reception.
